# 제트카 사이트 MCP

제트카 공식 홈페이지의 신차장기렌트·중고장기렌트·화물차구독 목록과 차량 상세를 조회합니다. Codex에서 제트카 플러그인을 선택하면 사용할 수 있습니다.

## Codex에 요청하기

| 도구 | 요청 예시 | 결과 |
| --- | --- | --- |
| `list_jetcar_vehicles` | “제트카 중고장기렌트 차량 목록 보여줘.” | 신차장기렌트, 중고장기렌트 또는 화물차구독의 차량명, 요약 정보, 표시 월 요금, 대표 사진과 상세 링크 |
| `get_jetcar_vehicle` | “`https://jetcar.co.kr/sub0301/4865` 이 차량의 사진과 가격, 옵션, 계약 조건 가져와줘.” | 차량명, 연식·주행거리·연료 등 주요정보, 원본과 썸네일 사진 링크, 가격표, 옵션, 계약·보험 조건 |
| `capture_jetcar_vehicle_section` | “이 차량의 주요정보만 홈페이지 화면 그대로 캡처해줘.” | 캡처한 영역의 PNG 파일과 저장 경로 |

### 목록 조회

`category`는 `new`(신차장기렌트), `used`(중고장기렌트), `truck`(화물차구독), `all`(전체) 중 하나입니다. 기본값은 `all`과 `page: 1`입니다. 사이트가 내보낸 페이지 순서로 반환합니다. 전체 조회의 `page`는 세 카테고리에 각각 적용합니다.

`nextPage`가 있으면 다음 쪽을 요청할 수 있습니다. 한 페이지가 16대로 꽉 찬 경우 사이트 응답만으로 뒤에 차량이 더 있는지 알 수 없어 `hasMore`는 `null`입니다. 다음 쪽이 비어 있거나 현재 목록의 `nextPage`가 `null`이면 해당 카테고리 조회를 마칩니다.

### 상세 조회

`vehicleUrl`에 목록에서 반환된 `url` 또는 차량 상세 링크를 전달합니다. 한 번 조회하면 아래 정보가 함께 돌아옵니다.

| 결과 항목 | 내용 |
| --- | --- |
| `title`, `additionalInfo`, `keyInformation` | 차량명, 추가 설명, 연식·주행거리·연료 등 주요정보 |
| `images` | 홈페이지 게시 순서의 원본 사진 주소 `url`과 제공되는 경우 `thumbnailUrl` |
| `prices`, `priceNotes` | 화면에 표시된 보증금, 계약기간, 월 요금, 약정 주행거리, 초기비용·부가세 안내 |
| `quoteOptions` | 견적 화면에 공개된 선택지, 기본 선택 여부, 표시된 월 추가금 |
| `options`, `contract`, `insurance` | 차량 옵션과 계약·보험 조건 |

가격표는 조회 시점의 기본 조건을 보여줍니다. 견적 화면에서 조건을 바꿨을 때의 요금은 홈페이지에서 확인할 수 있습니다. 사진을 원본 파일로 받아야 할 때는 `images[].url`에 직접 HTTP 요청을 보낼 수 있습니다.

### 홈페이지의 특정 부분 캡처

`capture_jetcar_vehicle_section`에 `vehicleUrl`과 `section`을 전달합니다. `section`은 `주요정보`, `가격정보`, `옵션` 중 하나입니다. 여러 영역은 영역별로 한 번씩 호출합니다.

| 요청 | 사용 방법 |
| --- | --- |
| 사진, 가격표 값, 주요정보 또는 옵션 데이터 | 사이트 MCP로 조회합니다. 원본 차량 사진은 조회한 URL로 가져옵니다. |
| 표 내용을 이미지로 만들기 | 사이트 MCP로 값을 읽어 표 이미지로 구성할 수 있습니다. |
| 홈페이지의 주요정보·가격정보·옵션 캡처 | 사이트 MCP의 캡처 도구가 해당 영역만 PNG로 저장합니다. |
| 홈페이지의 그 외 영역 캡처 | Codex 브라우저 도구로 해당 영역을 캡처합니다. |

캡처 도구는 설치된 Chrome 또는 Edge를 Playwright로 백그라운드에서 실행해 비로그인 상태의 PC 웹 화면을 캡처합니다. `가격정보`는 견적 계산기가 있는 차량에서 기본 조건의 견적 영역을 담고, 그 외 차량에서는 가격표와 안내를 담습니다. PNG는 사용자 홈의 `Downloads/Jetcar`에 저장합니다. 호출 결과의 `filePath`에서 파일을 열 수 있습니다.

원고 제작이 함께 요청됐으면 조회한 값으로 스마트에디터 표를 구성하거나, 요청한 영역의 캡처 이미지를 글에 사용합니다. 임시저장까지 요청됐으면 해당 카페 게시판으로 원고를 넘깁니다.

## 홈페이지 연결

공개 데이터는 HTTP로 먼저 가져옵니다. 첫 목록과 상세는 공개 페이지에 GET을 보내고, 목록 2쪽부터는 사이트의 무한 스크롤에 쓰이는 `POST /jetcar/ajax_list.page.php`로 해당 쪽을 요청합니다. 사이트가 반환하는 HTML에서 필요한 항목을 추출합니다. 이 조회에는 브라우저와 관리자 로그인이 필요 없습니다.

## 조회 속도

Windows와 Node.js 22에서 공개 홈페이지 응답과 파싱을 포함한 조회 왕복 시간을 각 5회 측정했습니다. 원본 사진 파일 다운로드는 별도입니다.

| 조회 | 응답 수 | 중앙값 | 측정 범위 |
| --- | ---: | ---: | ---: |
| GV80 상세 | 사진 링크 27개 | 124 ms | 80~148 ms |
| 신차 1쪽 | 16대 | 503 ms | 435~513 ms |
| 중고차 1쪽 | 16대 | 508 ms | 487~513 ms |
| 화물차 1쪽 | 3대 | 159 ms | 157~167 ms |
| 전체 1쪽 | 35대 | 498 ms | 485~555 ms |
| 중고차 2쪽 | 16대 | 489 ms | 475~504 ms |

전체 목록은 세 분류를 동시에 요청합니다. 같은 PC에서 캡처 도구로 신차와 중고차의 네 영역을 한 번씩 저장하는 데 요청당 약 0.9~1.5초가 걸렸습니다. 이 시간에는 브라우저 실행과 PNG 저장이 포함됩니다.

## 개발

저장소 루트에서 빌드합니다.

```bash
npm ci --prefix mcps/jetcar-site
npm run package:plugin --prefix mcps/jetcar-site
```

설치본의 `mcp.json`은 `plugins/jetcar/mcps/jetcar-site/launch.mjs`를 실행합니다. 빌드한 `runtime.tar.gz`에 서버와 Playwright 라이브러리가 포함됩니다. 캡처에는 PC에 설치된 Chrome 또는 Edge가 필요합니다.
