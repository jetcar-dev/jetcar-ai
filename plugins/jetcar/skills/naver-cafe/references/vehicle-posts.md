# 차량 입고·홍보 글 작성

차량 상세 페이지, 사용자가 첨부한 원고·사진, 대화에서 확정한 정보를 사용한다. 원고를 그대로 올려 달라는 요청에는 원문과 차량 조건을 유지하고 필요한 스마트에디터 서식만 적용한다.

## 새 원고 작성

1. 사용자가 지정한 차량을 찾는다. 차종이 같아도 차량이 여러 대면 상세 링크, 차량 번호 또는 매물번호로 구분한다. 차량 정보를 읽을 수 없으면 필요한 항목만 요청한다.
2. 글의 목적에 맞춰 확인된 정보를 고른다.

   | 항목 | 반영할 정보 |
   | --- | --- |
   | 제목 | 차종과 입고 또는 장기렌트 안내. 연식이나 트림은 확인됐을 때만 붙인다. |
   | 차량 소개 | 연식, 주행거리, 트림, 색상, 주요 옵션, 차량 상태 중 출처에서 확인한 정보. 사진에서 확인하기 어려운 옵션은 차량 상세 정보나 원고에서 확인한다. |
   | 장기렌트 조건 | 확인된 월 렌트료와 그 조건을 함께 쓴다. 계약 기간, 약정거리, 보증금·선납금, 부가세 등은 출처에 나온 기준을 유지한다. 월 렌트료와 차량 판매가는 각각 원래 이름과 단위를 사용한다. |
   | 사진·문의 | 사용자가 준 사진 순서와 대표사진 선택을 반영한다. 문의 연락처, 상세 페이지 주소, 방문 장소는 사용자가 주었거나 차량 안내 자료에 명시된 값을 사용한다. |

3. 제목 아래에 입고 요약, 차량 정보, 사진, 문의 안내를 읽기 좋은 순서로 둔다. 자료에 없는 부분은 생략하고, 사용자가 꼭 넣어 달라고 한 정보만 확인한다. 사고 이력, 재고 상태, 인도 가능일, 승인 조건은 자료에서 확인된 내용만 쓴다.
4. 글을 새로 꾸며 달라고 했으면 짧은 첫 문단에 정렬과 굵기를, 입고 요약에는 인용구를 활용할 수 있다. 차량 사양은 항목마다 줄을 바꿔 읽기 쉽게 쓴다. 사용자가 지정한 인용구 번호와 사진 순서를 우선한다.

## 요청 예시

> 중고차 장기렌트카 입고 게시판에 캐스퍼 임시저장해줘. 2023년식이고 24,000km야. 앞모습 사진, 실내 사진 순서로 넣고 실내를 대표로 해줘.

- 게시판 목록에서 **중고차 장기렌트카 입고**를 찾아 링크를 사용한다.
- 제목은 `2023년식 캐스퍼 입고 안내`로 작성할 수 있다. 본문에는 `2023년식`과 `주행거리 24,000km`를 넣는다. 사진 파일을 식별할 수 있으면 순서대로 추가하고 `representativeImage`는 `2`로 지정한다.
- 렌트료·보증금이 제공되지 않았으면 그 부분은 생략한다. 글을 저장하는 데 필요한 사진의 파일명만 확인되면 진행한다.

> 지난번 캐스퍼 임시글에 실내 사진만 추가하고, 그 사진을 대표로 바꿔줘.

- 기존 임시글의 제목과 게시판을 확인해 해당 ID에 사진을 추가한다. 대표 번호는 기존 사진 수에 새 사진의 순서를 더해 계산한다. 기존 사진 수가 확인되지 않으면 사용자에게 번호를 확인하거나, 사진을 먼저 추가해도 되는지 확인한 뒤 저장 결과의 `imageCount`를 사용한다.

> 입고 글 내용 한번 보여줘. 글꼴은 크게 하고 표도 넣고 싶어.

- 채팅에 원고와 차량 정보 표를 보여준다. 카페에 옮길 때는 [스마트에디터 ONE 입력 형식](../../smart-editor-one/references/input.md#서식을-블록으로-옮기기)에 따라 글자 크기와 표를 지정한다.
