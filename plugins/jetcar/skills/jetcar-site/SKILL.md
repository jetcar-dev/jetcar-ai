# 제트카 사이트

## 도구 선택

제트카 사이트 MCP와 직접 HTTP 요청으로 가능한 작업은 이 경로를 우선 사용한다. 필요한 정보나 산출물을 HTTP에서 얻을 수 없는 경우에는 브라우저 도구를 사용한다. 조회와 화면 캡처가 한 요청에 들어오면 차량 데이터는 MCP로 조회하고 화면이 필요한 영역에 브라우저를 쓴다.

| 요청 | 처리 |
| --- | --- |
| 링크로 차량 상세 조회 | `get_jetcar_vehicle`에 `vehicleUrl`을 전달한다. |
| 차량 목록 또는 차량 찾기 | `list_jetcar_vehicles`에 `category`와 필요한 `page`를 넘긴다. 상세가 필요하면 목록 항목의 `url`로 이어서 조회한다. |
| 원본 사진 파일 가져오기 | 상세의 `images[].url`을 직접 HTTP로 받아 요청한 작업에 사용한다. |
| 홈페이지 그대로 주요정보·가격정보·옵션 캡처 | `capture_jetcar_vehicle_section`에 `vehicleUrl`과 `section`을 전달한다. |

목록은 `new` 신차장기렌트, `used` 중고장기렌트, `truck` 화물차구독, `all` 전체를 사용한다. `all`은 카테고리마다 같은 쪽을 가져온다. 원하는 수량이 아직 모자라고 `nextPage`가 있으면 다음 쪽을 조회한다. `hasMore: null`은 다음 쪽 존재가 확인되지 않은 상태다.

가격을 안내할 때 해당 행의 보증금, 계약기간, 약정 주행거리를 함께 적는다. `prices`는 기본 조건, `quoteOptions`의 추가금은 견적 선택지다. 실제로 선택한 조건의 최종 요금이 필요하면 홈페이지의 견적 결과를 확인한다. 차량번호나 모델명이 비슷해 대상을 고를 수 없으면 차량 링크를 확인한다.

## 특정 영역 캡처

1. 차량 링크와 영역이 주어졌으면 `capture_jetcar_vehicle_section`을 호출한다. `section` 값은 `주요정보`, `가격정보`, `옵션`이고, 요청한 영역이 여러 개면 각각 호출한다. 도구가 Playwright로 공개 PC 페이지의 해당 영역을 캡처하고 PNG의 `filePath`를 반환한다.
2. 계약 조건이나 보험 조건처럼 캡처 도구에 없는 영역의 실제 화면이 필요하면 브라우저 도구로 해당 영역만 캡처한다. 표 내용을 새 이미지로 만들기를 요청한 경우에는 조회한 값을 사용한다.
3. 캡처를 전달할 때 `filePath`의 PNG가 요청한 차량과 영역인지 확인한다. 차량 원고를 만들 때는 요청받은 영역의 이미지를 지정한 위치에 넣는다. 카페 임시저장까지 요청됐으면 네이버 카페 도구를 사용한다.
